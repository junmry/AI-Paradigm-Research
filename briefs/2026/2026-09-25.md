# 2026-09-25｜AI 底层与管理学交叉研究周报

覆盖：2026-09-19—2026-09-25（北京时间）

## 本周判断
本周没有足够证据宣布基础模型范式被改写，但有一个值得追踪的共同方向：搜索策略与团队组织正在从外围工程变成智能能力本身的研究变量。全部为新预印本，尚无独立复现。

## Self-Organizing Agent Teams Learn to Reason Together
原文：https://arxiv.org/abs/2609.22682

SAT 学习角色、对话阶段、参与规则、信息流与综合规则。五个数学/物理 benchmark 平均 accuracy：最强独立成员 48.8%，compute-matched 单 Agent 58.7%，独立答案 perfect router 59.0%，SAT 66.7%。AIME 2026 上 SAT 71.2%，比 routing-oracle coverage 57.8% 高 13.4 个百分点。跨 8 个 benchmark，demonstrability 与团队收益相关（Spearman rho=0.90, p=0.005），但这不是因果识别。

管理学价值：真正值得研究的不是 Agent 数量，而是知识分布、正确推理的可识别性、组织搜索结构与选择能力。下一步应固定候选池，随机操纵 reasoning certificate 的可验证性，观察 verifier AUC、selection accuracy 与 final accuracy。

## Beyond Repeated Sampling: Learning Search Policies for LLM Reasoning
原文：https://arxiv.org/abs/2609.26704

论文将 test-time reasoning 拆成“搜索什么”与“如何完成答案”：小型 concept generator 先产生概念/策略，再由冻结的大 answer generator 展开；前者通过 RL 学习提高后者成功率。作者报告该策略可迁移到训练时未见的 answer generator，包括不同模型家族。核心变化是把搜索方向本身变成可训练的元策略，而不只是增加随机采样次数。

## 思想演化
Repeated Sampling → 学习语义搜索；Routing/Voting → 自组织团队。共同问题是：计算预算应该如何被组织？

## 项目机会
Institution-Aware Agent Teams：在相同模型与 token budget 下比较固定层级、自组织团队、自组织+独立审计，联合测量任务成功、验证质量与协调成本。

Verifiable Demonstrability：给 reasoning certificate 增加可复核外部步骤与 provenance；先以普通结构化记录为强基线，只有跨组织互不信任、无法共享原始数据时，再检验更强验证机制是否真正改变可达能力。

本期不为覆盖五学科而硬塞区块链或 ZKML；没有机制必要性时，缺席本身就是筛选结果。
