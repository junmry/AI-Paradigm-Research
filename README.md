# AI Paradigm Research · 范式突破研究档案

**AI × 认知科学 × 信息系统 × 区块链 × 密码学**

这是一个**独立的跨学科研究档案**，每周五（北京时间）留存一份中文技术研究简报。目标不是罗列新模型、新论文或热门项目，而是识别改变问题定义、计算机制、认知解释、信息协作机制和可信性边界的研究。

> 核心问题：一项工作是否提出了自己的可证伪思路？如果结论成立，究竟改变了什么？如果失败，是否明确验证了重要的假设或能力边界？

## 研究范围

| 领域 | 重点关注的问题 |
| --- | --- |
| 人工智能 | 新学习与推理范式、模型结构、智能体机制及能力边界 |
| 认知科学 | 记忆、概念形成、元认知、因果推理、具身与分布式认知的可检验机制 |
| 信息系统 | 信息获取与反馈、人机与多智能体协调、共享知识、社会技术系统中的实际效果 |
| 区块链 / 分布式系统 | 共识与状态一致性、身份、开放网络中的互不信任协作及其代价 |
| 密码学 | 零知识与可验证计算、MPC/FHE、隐私保护、来源验证与威胁模型 |

**不强迫单篇论文同时覆盖五个领域。** 优先看真正的机制碰撞，例如认知假说是否催生可测试的智能架构；密码协议是否让以前无法安全协作的智能体具备了新能力；信息系统中的实证失败是否迫使我们修改智能理论。

## 阅读与归档原则

1. **拒绝“西红柿炒蛋”式同质化：** 仅换组件、提示词、数据集、训练配方或堆算力，不自动构成创新。
2. **宁缺毋滥：** 本周没有可信的范式突破就明说，不编造里程碑或凑篇数；认真对待高信息量的失败结果。
3. **证据优先：** 区分作者主张、论文中的数据、独立复现及我们的审慎推断；核查对照、消融、计算预算、污染、可复现性和适用边界。
4. **审查跨领域必要性：** 没有链或密码学是否同样成立？到底改变了什么信任假设？可验证执行不等于可验证语义正确性。
5. **保留研究脉络：** 每期附原文、代码、评测链接、全文阅读优先级及后续可证伪实验；新证据改变旧结论时交叉链接并注明修正。

## 仓库约定

- `briefs/YYYY/YYYY-MM-DD.md`：单期完整 Markdown 简报，按北京时间周五日期命名。
- `briefs/README.md`：按发布日期追溯每期全文及后续修正。
- `RESEARCH_PROTOCOL.md`：筛选标准、证据审查流程、报告格式与可证伪实验要求。
- 不存储受限论文全文、私密数据、账户凭据或未经授权的内容；引用公开论文原文链接而非擅自镜像原文。

## 进阶定位：计算机科学 × 管理学研究方法

周报为未来管理学研究生学习增加 **信息系统、组织理论、决策科学与研究设计** 视角：在解释底层智能机制之后，追问其组织层含义需要哪些中间机制、反事实与因果证据。每期精选仍约 2–3 项，强调思想谱系、关键证据、理论构念与分析层级、研究设计拆解及 1–2 个可证伪的原创课题；不为管理学应用牺牲技术原创性，不把 AI 跑分直接当作组织绩效。
